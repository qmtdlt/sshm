# sshm

在当前终端中管理本地 SSH 连接。输入 `sshm` 打开列表，选中连接后按 Enter，退出 SSH 后回到列表。

使用 Rust + Ratatui + Crossterm；实际连接调用系统 OpenSSH。一个可执行文件，不需要额外安装 Rust 运行环境。当前名称为 `sshm`。

## 构建与运行

macOS 安装包与在线更新已有实现，正在本地验收，尚未正式发布；Windows 安装器另行实施；Linux x64 已提供公网一条命令安装，见 [Linux 安装说明](docs/linux-installation.md)。详见 [跨平台安装与在线更新待办](docs/installation-and-updates.md) 和 [macOS 安装与分发](docs/macos-distribution.md)。

开发环境需要 Rust 稳定版和对应平台的链接工具。运行环境需要终端和 PATH 中的 `ssh`。

```sh
cargo build --release --locked
cargo run -- --help
cargo run
```

Windows 构建结果：`target/release/sshm.exe`；macOS/Linux：`target/release/sshm`。

在本项目目录的 PowerShell 中启动：

```powershell
.\target\release\sshm.exe
```

将可执行文件放进 PATH 后，即可直接输入 `sshm`。项目不会自动修改系统 PATH。

## 命令

| 命令 | 行为 |
| --- | --- |
| `sshm` | 打开交互式列表 |
| `sshm list` | 打印连接列表并退出，支持输出重定向 |
| `sshm connect <名称>` | 按完整名称直接连接，结束后回到命令行 |
| `sshm add` | 新增表单 |
| `sshm add --connect` | 新增表单，首个保存按钮为“保存并连接” |
| `sshm edit <名称>` | 编辑表单 |
| `sshm remove <名称>` | 确认后删除记录 |
| `sshm setup-key <名称>` | 首次配置本机密钥登录，先确认再执行 |
| `sshm import [路径]` | 选择要导入的 Host 别名，默认 `~/.ssh/config` |
| `sshm update --check` | 检查 macOS 稳定版更新，不下载安装包 |
| `sshm update` | 确认后下载并校验，通过系统安装器升级；需要管理员授权 |
| `sshm --help` / `sshm <子命令> --help` | 帮助 |
| `sshm --version` | 版本 |

名称忽略大小写后唯一，支持中文和空格。命令行中包含空格的名称需要引号，例如 `sshm connect "生产 数据库"`；名称以 `-` 开头时使用 `sshm connect -- "-名称"`。找不到名称会报错，不会自动连接到模糊匹配项。

退出码：正常操作或取消为 0；本工具错误为 1；命令参数错误为 2；直接连接及独立表单发起的连接返回 SSH 退出码。

## 交互

主列表按最近使用排序；未使用项按名称排序。列表较窄时依次隐藏最近使用、标签、用户列，最低建议 38 列 × 12 行。

| 按键 | 行为 |
| --- | --- |
| ↑ / ↓ 或 j / k | 选择连接 |
| PageUp / PageDown，Home / End | 翻页、跳到首尾 |
| Enter | 连接 |
| / | 搜索名称、地址、用户、标签；多个词同时匹配，不区分大小写 |
| 搜索中 Enter | 保留筛选，回到列表 |
| Esc | 清空筛选；在其他界面取消操作 |
| a / e / d / i | 新增 / 编辑 / 删除 / 导入 |
| s | 为选中连接设置密钥登录 |
| g | 登录 Google Drive / 打开同步管理 |
| p | 手动拉取并合并云端，再推送待发送修改 |
| ? | 快捷键帮助，Esc 或 q 关闭 |
| q / Ctrl+C | 在主列表退出 |

输入框中的字母不会触发列表快捷键。搜索中的 Ctrl+C 退出输入，保留筛选。

新增字段：名称、主机地址、用户名、端口（默认 22）、私钥路径（可选）、标签（可选，逗号分隔）。IPv6 地址不带方括号，端口单独填写。私钥路径支持 `~`、相对路径和带空格的绝对路径；相对路径保存时转换为绝对路径。

主机、用户名和端口填写完并离开字段时，会自动检测本机密钥；匹配到唯一候选就填入私钥路径。新增/编辑手动连接时按 F2，可直接从已有密钥列表选择，不必记住文件位置。手动指定的路径优先；修改目标地址时会重新计算本次表单自动填入的建议。

Windows 默认检查 `%USERPROFILE%\.ssh` 和其中的 `config`，macOS/Linux 检查 `~/.ssh`。先读取静态 `Host`、`HostName`、`User`、`Port`、`IdentityFile` 和 `Include` 映射；输入的是 IP 时也会反查配置别名，并区分账号和端口。单个匹配密钥优先，其次是唯一的标准默认密钥；多个候选交给用户选择，不凭文件名里的 IP 猜测归属。

已有连接没有设置密钥路径时，连接前也会自动检测并使用唯一匹配项，无需重新添加连接。未匹配时保留系统 SSH 的默认密钥和 agent 行为。自定义名称的密钥通过同目录下的 `.pub` 配对展示；扫描不读取私钥内容、不执行 `Match exec`、不探测远端，也不把 `known_hosts` 或 `authorized_keys` 当成登录私钥。复杂动态配置无法静态确认时不自动选定，仍由系统 SSH 处理，或从列表手动选择。

测试或便携环境可以使用 `SSHM_SSH_DIR` 指定自动检测的目录；它只改变本工具的检测位置，不改变系统 SSH 自身的配置查找规则。

表单通过 Tab / Shift+Tab 切换，Enter 进入下一字段或激活按钮，左右键切换按钮。按钮为“保存”“保存并连接”“取消”；`add --connect` 中前两个按钮为“保存并连接”“仅保存”。有修改时取消会询问是否放弃，默认继续编辑。输入框支持光标移动、Home/End、Ctrl+A/E、Ctrl+U/K，以及粘贴。

删除弹窗默认取消，只删除本工具记录，不删除私钥或原 SSH 配置。

## 一次配置，后续使用密钥登录

首次连接时会自动进入登录方式页面，默认选中“配置密钥并连接”。直接按 Enter 确认，按 SSH 提示完成首次认证，配置并验证密钥后自动进入会话；后续连接直接使用已配置的方式。列表 Enter、`sshm connect` 和“保存并连接”都走同一流程，无需先记住 `s` 快捷键。

“仅本次密码 / 原方式登录”是临时选项，不保存密码、不配置密钥，也不会记录为免密码登录；下次仍会显示登录方式页面。取消不会连接服务器。首次登录说明需要至少 60 列 × 20 行。

已有连接升级后会显示一次登录方式页面；已有密钥可直接复用，不要求重新添加连接。验证成功后保存 `key_login_configured` 状态，修改主机、用户名、端口或密钥路径会清除此状态，避免将旧服务器的验证结果沿用到新目标。

需要重新设置时仍可按 `s`，或运行 `sshm setup-key "连接名称"`。独立密钥设置确认页默认取消，按 Tab 选中确认，再按 Enter。

流程是：先匹配本机已有密钥，有多个目标匹配项时显示选择列表 → 确认后验证已有密钥/agent 能否直接登录 → 已可用则直接复用；尚未授权时才追加所选密钥的公钥 → 禁用密码认证再次验证 → 成功后保存密钥路径和完成状态，再进入 SSH 会话。没有匹配密钥且默认登录也不可用时，才生成专用 Ed25519 密钥，不要求从其他服务器的无关密钥中猜选。需要首次授权时按 SSH 提示输入服务器密码，以后按 Enter 连接使用密钥。

自动配置适用于 Linux/macOS 远端的默认 `~/.ssh/authorized_keys`。需要远端允许公钥登录且用户能写入自己的 `.ssh`；服务器强制二次认证或采用自定义公钥路径时，自动验证可能失败。不会更改 sshd 配置、关闭密码登录或覆盖已有公钥。

为了避免每次再输入密钥口令，生成的专用私钥没有额外口令，保存在配置目录的 `keys/<连接ID>/id_ed25519`；Unix 使用 0700 目录和 0600 文件权限，Windows 使用只授权当前用户的受保护 ACL。私钥本身是登录凭据，不应分享或放进普通云同步。希望使用加密私钥的用户，可以自行设置密钥与 ssh-agent，再填写已有私钥路径。

已有密钥只引用原路径，不复制、覆盖、改权限或重设口令。公钥文件缺失时，通过 ssh-keygen 读取公钥而不改写已有文件；已有私钥带口令时仍需按 SSH 提示解锁，配合 ssh-agent 可缓存解锁状态。

同一连接重复设置会复用密钥，远端按公钥数据去重，即使注释不同也不会重复追加或绕过已有公钥限制。验证失败时保留原连接设置和已生成密钥，以便重试；已追加到服务器的公钥也保留。导入项的本机密钥以 `local_identity_file` 单独保存，不修改原 SSH 配置文件。

删除连接不会自动撤销服务器授权或删除私钥；要撤销此电脑的访问，可在服务器 `authorized_keys` 中删除注释为 `sshm:<连接ID>` 的对应公钥行。换电脑后需要在新电脑上重新设置密钥。

## SSH 连接与配置导入

选择连接后，工具恢复终端的普通模式，把标准输入、输出和错误流直接交给 `ssh`。密码、私钥口令、首次服务器身份确认由 OpenSSH 自行处理，不捕获或保存密码，不修改 known_hosts 策略。SSH 会话内按键属于 SSH，`q` 不会退出管理器；输入 `exit` 结束远端 shell。

列表中发起的连接正常结束后自动返回列表；非零退出或启动失败时保留错误输出，按 Enter 返回。原搜索条件和选中项保留。直接命令或独立表单发起的连接结束后返回原命令行。

最近使用记录系统 SSH 子进程成功启动的时间，不能用来判断远端登录是否成功。找不到 `ssh` 时不会更新该记录。

导入通过 Space 勾选、a 全选/取消全选、Enter 确认、Esc 取消。名称冲突、重复引用会跳过并报告。导入项可编辑名称和标签，其他参数继续在原文件中维护。

导入只枚举明确的 `Host` 别名；通配、否定规则不生成记录。支持带引号的名称、`Host=alias` 和静态 `Include`。相对 Include 按用户 SSH 配置的规则从 `~/.ssh` 解析；带 `%` 或 `$` 的动态 Include 不展开，并在导入结果中提示。扫描不会运行 `Match exec` 或其他配置命令。

连接导入项时使用 `ssh -F <原配置文件> -- <原别名>`，由 OpenSSH 解释跳板机等规则；`-F` 不会自动加载系统级 ssh_config，需要时在原文件使用 Include。引用文件移动或删除后会提示错误，工具不复制或重写该文件。

## 数据位置

默认配置是下列目录内的 `connections.json`：

| 平台 | 目录 |
| --- | --- |
| Windows | `%APPDATA%\sshm` |
| macOS | `~/Library/Application Support/sshm` |
| Linux | `$XDG_CONFIG_HOME/sshm`，未设置时 `~/.config/sshm` |

可通过环境变量 `SSHM_CONFIG_DIR` 指定其他目录，适合便携运行或测试。只读命令不会创建配置文件。

写入通过文件锁和临时文件替换完成；多窗口编辑同一条记录时会报告冲突，取消后重新打开即可。配置损坏或版本不支持时拒绝覆盖。备份时保存 `connections.json`；`connections.lock` 是锁文件，无需备份。

本地格式已升级为 v2；首次写入旧版配置前，将原始字节备份到 `connections.v1.backup.json`。不要用旧版程序打开 v2 配置。备份中如果还包含相同路径来源的另一份旧配置，会另外使用唯一文件名保存。

## Google Drive 同步

主列表底部按 `g` 选择「登录 Google Drive 以同步」。新增、编辑、删除后合并 1 秒内的连续修改再自动推送；**按 `p` 才拉取并合并云端，再推送待发送修改**。登录和启动均不自动拉取，也不定时检查云端；新电脑登录后按 `p` 获取连接。离线时照常使用本地连接，未推送的修改保留并退避重试，下次启动也会继续推送；程序退出后不常驻。

主列表和同步管理界面均可按 `p` 拉取并合并云端；拉取失败后按 `p` 重试，不自动重复拉取。同步管理还提供 `l` 登录或更换账号、`c` 查看冲突、`o` 退出登录。授权期间 Esc 取消；长授权链接可用上下键滚动。更换账号必须按 `y` 确认将当前本机连接合并到新账号，`n` 或 Esc 取消。退出登录不删除连接或云端数据。

| 数据 | 同步范围 |
| --- | --- |
| 名称、标签、连接 ID、手动连接的主机/用户名/端口 | 同步到用户 Drive 的应用专属隐藏目录 |
| 导入连接 | 仅同步来源 ID 与 Host 别名，新电脑需绑定自己的 SSH 配置文件 |
| 私钥内容及路径、SSH 配置路径、最近使用、密钥登录验证状态 | 仅留本机 |
| Google 刷新令牌 | 本机系统凭据存储；Linux 远程模式可确认后存入权限受限文件，不写入连接 JSON |

新电脑的导入项显示「待绑定配置」；按 Enter 或 e 选择本机文件，同来源的全部别名核对成功后一起绑定。已绑定导入项可在编辑表单按 F2 更换本机文件。绑定不复制、改写或执行 SSH 配置。手动连接沿用本机密钥发现和首次连接流程，不会从旧电脑获取 SSH 私钥。

两台电脑并发修改同一连接时，保留带「冲突」后缀的副本，不按电脑时钟覆盖。删除多余副本即可保留所需版本；删除与编辑冲突时，保留编辑版本，编辑并保存即可确认保留。不同 ID 的同名连接会加后缀保留，不会仅凭地址猜测是否是同一条。

程序只对可同步字段产生变更；外部编辑 JSON 也会在运行期间检测。文件暂时缺失、损坏或格式不支持时暂停同步，不当作删除全部。多窗口由一个后台线程持有同步锁负责网络请求，其他窗口照常操作本地配置。SSH 会话内不会插入同步输出，返回列表后显示最新状态。

本地文件检查不调用 Google API。没有待推送修改、也未按 `p` 时，不发起 Drive 查询或定时刷新令牌；自动推送仅追加本机变更，不先读取或覆盖其他电脑的数据。冲突在手动拉取后呈现。

配置和令牌不经过 sshm 运营方服务器；云端 JSON 不做端到端加密，Google 可以接触其内容。本机浏览器登录在系统凭据存储不可用时仅维持本次登录。SSH 会话按 g 自动进入远程登录，也可在同步页面按 r：按提示建立 SSH 转发，在其他电脑浏览器授权。Linux 可选择“记住登录”，令牌以 0600 权限保存在本机文件中，重启自动恢复，无需每次输入密码；文件不加密，root 可读。详见 [远程登录说明](docs/google-drive.md#远程登录无桌面-linux)。

普通源码构建默认未附带 Google 客户端配置；打包脚本复用开发者已有配置，不需要为 Mac 或新版本重新注册。配置方法详见 [Google Drive 接入说明](docs/google-drive.md)。未配置时会明确提示，不打开无效授权页面。测试使用本地模拟服务，不代表已完成真实账号授权验收。

当前不包含密码保存、文件传输、多会话分屏、后台常驻、独立的隧道/跳板机编辑器，也不会记录在工具外执行的 SSH 命令。

## 验证与代码结构

```sh
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets --locked
cargo build --release --locked
```

测试全部使用临时目录。终端集成测试创建隐藏的伪终端并编译本地 SSH 替身，验证键盘输入、终端继承、返回列表、退出码及密钥配置成功/失败流程；不连接真实服务器。原生 OpenSSH 检查对测试配置执行 `ssh -G`，并在临时目录执行 ssh-keygen。公钥安装脚本的本地测试需要 POSIX sh；Windows 可通过 `SSHM_TEST_SH` 指定 Git Bash 的 sh.exe，测试只修改临时 HOME 中的文件。

`src/cli.rs` 定义命令，`model.rs` 定义记录与校验，`store.rs` 管理本地数据，`import.rs` 枚举 SSH 别名，`discovery.rs` 静态发现本机密钥，`ssh.rs` 启动 SSH，`keys.rs` 配置密钥，`permissions.rs` 限制生成密钥的权限，`ui/` 实现界面与交互状态，`sync/` 实现可移植变更模型、Google OAuth/Drive 请求及后台同步。

CI 配置分别在 Windows、macOS、Linux 执行测试和构建；不同系统需要各自的二进制文件。
