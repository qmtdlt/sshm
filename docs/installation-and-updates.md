# 跨平台安装与在线更新待办

记录日期：2026-11-03

状态：macOS 安装包、更新模块和产物流水线已实现，ARM64 本机首次安装及启动验收已完成；正式分发、真实版本升级和跨机验收尚未完成。详见 [macOS 安装与分发](macos-distribution.md)。

## 用户目标与实施顺序

- 用户安装后，新开终端即可输入 `sshm` 启动，不需要输入程序路径，使用体验参考 yazi、lazygit。
- 支持在线版本更新，升级后仍可直接使用 `sshm`。
- 先实施 macOS，再实施 Windows；Linux 已确定先做 x64 通用压缩包与一条命令安装脚本，暂不做 deb/rpm 和 Linux 自动更新。
- Mac 接入、打包和更新不得破坏现有 Windows Google Drive 接入。
- 本文保留原需求与验收清单；新增代码不等于全部验收完成，下方未完成项保持未勾选。

## 当前基础

- 项目是 Rust 终端程序，实际 SSH 连接由系统 OpenSSH 执行。
- 已在本机生成内置现有 Google OAuth 应用配置的 macOS ARM64 release 程序，并检查版本及帮助命令；不代表真实授权或双机同步已验收。
- 现有源码支持运行时配置文件与构建时 OAuth 注入；真实客户端配置不在 Git 中。
- 已新增 pkg 构建脚本、在线更新命令和产物准备流水线；ARM64 已完成系统级首次安装与启动验收，尚未对外发布。
